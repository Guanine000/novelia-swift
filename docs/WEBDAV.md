# WebDAV 同步

[← 返回 README](../README.md) · [功能说明](FEATURES.md) · [本机构建与分发](BUILD.md) · [许可与第三方软件](LICENSES.md)

Novelia iOS 通过 WebDAV 同步在多台设备间共享书籍、阅读进度和部分设置，可手动同步，也可开启自动同步。

## 设置

1. 在“我的 → WebDAV 同步”打开同步开关。
2. 填入可写的 HTTPS WebDAV 文件夹地址、用户名和密码（或应用密码）。密码保存在 iOS 钥匙串。
3. 按需独立开启书籍同步（书籍记录、上传书籍文件与阅读进度）、标签同步、阅读背景同步和导入字体同步。阅读时长统计另有默认关闭的统计同步开关，见[阅读时长统计](FEATURES.md#阅读时长统计)。

## 开始同步

- 在书库左上角点同步按钮开始。
- 同步过程中再次点按钮，可打开进度浮窗并取消任务（自动同步也可在这里取消）。
- 另一台设备配置相同地址并同步后，云端有而本机没有的书会出现在书库中，标为“未下载”。

## 云端书籍（按需下载）

为节省 WebDAV 流量，同步不会自动下载书籍文件：

- 本机的书照常上传到 WebDAV（手动与自动同步都会上传新书或较新的版本）。
- 本机没有的书只取回书籍记录；有封面的 EPUB 另外下载封面（每张只下载一次），TXT 与没有封面的 EPUB 不下载任何文件。
- 书库中这些书带云朵图标并显示“未下载”，可以排序、搜索和移入系列，阅读进度照常同步。
- 打开或在“更多”菜单中选择“下载”时会询问是否下载；确认后从 WebDAV 下载完整文件并直接打开。
- 本机已有的书不会被云端较新的版本自动替换。
- 本机网络小说 EPUB 可通过书库“更多 → 更新到最新章节”从网站重新获取；更新后下载时间改变，再同步可上传新版本。此操作获取网站当前内容，不是从 WebDAV 拉取新版，也不会改变其他设备已有旧文件的处理规则。
- 下载确认会显示文件大小。清单缺少大小的书显示“大小未知”，本机有相同版本的设备同步后补上。

### 从云端删除

- 删除本机书籍时可选择同时删除云端副本；未下载的云端书籍可在“更多”菜单中“从云端删除”。多选删除同样适用。
- 删除按书库当前合并显示的分组处理，同来源、同系列且内容相同的隐藏副本也会一并删除；确认框显示额外副本数。界面在本机与云端处理期间持续显示进度，完成或失败后再结束。
- 本机删除成功、云端删除失败时，书库底部显示可关闭的提示和“重试”，不会弹窗打断后续操作；云端书目仍保留，也可在书籍菜单中再次删除。只有云端确认成功后才移除书目及系列归属。
- 云端删除会从清单移除书目，并在清单中记下删除时间。**书籍删除记录仅保留最近 30 天**，下次成功的内容同步或新增云端删除时清除过期记录。在记录有效期内，其他设备同步时会删除各自本机的这本书（导入／下载时间早于或等于删除时间的版本），且不会再上传或显示它；完成提示会说明删除了几本。超过 30 天未同步的设备可能把旧书重新上传。
- 本机记录的导入／下载时间与云端清单的删除时间比较：导入／下载时间较晚时视为重新添加，照常同步；早于或等于删除时间的旧版本按删除处理。恢复云端书籍不重置原导入时间，阅读或修改文件时间也不会被当作重新导入。此判断依赖设备时间正常。直接在 WebDAV 网页删除文件不会生成 App 的删除记录，应使用 App 的“从云端删除”。
- 云端清单更新成功后，立即删除这些书使用、且清单中已没有其他书引用的底层文件，释放服务器空间；同内容的其他书仍在使用的文件保留。个别文件删除失败只会留下无用文件，不影响同步。
- 若另一台设备恰在删除的同时同步了内容相同的书，它引用的文件可能被删除，书库显示“云端文件缺失”。在仍有该书副本的设备上手动同步会补传缺失文件；没有任何副本时需重新导入。

## 自动同步

在“我的 → WebDAV 同步”打开“自动同步”（默认关闭）。设置页会醒目提示该功能不够可靠，建议以手动同步为主。自动同步与手动同步使用相同流程，同一时间只会进行一次。清单内容（书籍、书签、书库信息、进度、系列、标签、背景、字体）与阅读时长分别判断：只有阅读时长变化时，只同步阅读时长。

| 时机 | 行为 |
| --- | --- |
| 启动或回到前台 | 有未同步的改动，或距上次成功同步超过 10 分钟时同步，用于取回其他设备的改动 |
| 离开 App（进入背景） | 有未同步的改动或新的阅读时长时同步；系统只给几十秒，来不及完成就中断，下次回到前台再同步 |
| 书库、系列、书签或标签改动 | 改动停止约 1 分钟后，有未同步的改动才推送 |
| 网络恢复 | 有未同步的改动或上次失败时立即重试 |

- 同步传输期间发生的新修改仍保留为待同步；本次拉取合并也可能让下次触发再确认一次，不会把未上传的新修改当成已完成。
- **未同步的改动**：检查书籍记录、阅读位置、书库系列、书签和屏蔽标签是否已被最近一次成功同步覆盖，只计入已开启的同步项。阅读背景与导入字体不参与比较，由回到前台的定期同步带上。
- **暂停条件**：断网时等待恢复；低数据模式下不自动同步；未填写完整的服务器、用户名或密码时跳过。两次自动同步至少间隔 1 分钟，期间的改动留到之后的同步。
- **失败重试**：连续失败后依次等待 1、5、15、30 分钟再尝试，成功后恢复正常。清单内容与阅读时长分别记录失败和等待时间；清单内容同步失败时，本轮不再同步阅读时长，阅读时长失败不会撤销已完成的内容同步。失败信息显示在同步页和进度浮窗。
- **阅读时长**：开启阅读时长同步后，“立即同步”与自动同步都会包含它；按设备合并取最大值，重复或中断的同步不会重复累计。“同步阅读时长”按钮仍可只同步统计。
- **减少请求**：许多 WebDAV 服务限制请求频率，自动同步因此尽量少发请求。
  - 同步目录确认存在后，自动同步跳过逐级检查；手动同步和任何失败之后会重新完整检查。
  - 清单没有变化时不写回。
  - 阅读时长只下载有变化的设备文件，本机时长没变时不上传；旧格式统计文件 `reading-statistics.json` 每天最多检查一次。
  - 没有任何改动时，一次自动同步通常只读取一次清单；只读过书时大约再加两次请求。
- iOS 不保证 App 在背景中运行；从多工画面直接关闭 App 时不会推送，改动保留到下次打开时同步。

## 合并规则

| 内容 | 规则 |
| --- | --- |
| 书籍 | 网络小说按下载时间、文库书按导入时间逐本比较；本机较新时上传。本机没有的书记为云端书籍，打开时再下载 |
| 书库信息 | 文库与导入书籍在书库中修改的书名、作者、简介和封面，同一文件版本按修改时间合并，不重新下载书籍文件 |
| 阅读位置 | 按更新时间合并。网络小说记录章节序号；EPUB 记录整书与章内比例，便于在两种引擎间近似恢复；TXT 记录章节与分页单位 |
| 书库系列 | 每个系列和每本书的归属分别按修改时间合并 |
| 书签 | 随书籍同步，每个书签按修改时间合并，删除也会同步；只同步云端书目中的书的书签 |
| 标签屏蔽 | 按每个标签最后修改时间合并，解除屏蔽也会同步 |
| 阅读时长 | 每台设备只写自己的统计文件，读取时合并全部设备；同一设备取较大值，各设备相加显示 |

- **追加与恢复**：本地删除不会删除云端副本，后续同步时该书会显示为未下载的云端书籍。
- **避免重复上传**：两端相同的书沿用清单中已上传的文件，不重复读取和上传；本机按文件路径、大小与修改时间缓存文件哈希。
- **取消**：取消不会回滚已经传输或恢复的文件，远端目录清单在同步最后阶段写入。
- **多设备同时同步**：内容同步要求可靠的强 ETag 与条件请求。另一台设备刚写过清单时，本机会自动重新读取并重试（最多三次），仍冲突才提示失败。GET 不返回有效 ETag 时，会尝试查询确切文件的版本并重新条件读取；仍无法确认时停止内容同步，不进行无条件覆盖。阅读时长按设备独立保存，不受这一要求影响。
- **坚果云首次创建**：官方端点使用随机临时文件上传，再以禁止覆盖的 MOVE 建立清单，避免该服务忽略条件 PUT 创建。创建正式清单前先在独立随机文件上验证禁止覆盖、版本更新与拒绝旧版本写入是否有效；无法确认时停止。探测及上传的临时文件由本次操作清理，网络中断可能留下 `novelia-probe-*.cache` 或 `novelia-upload-*.cache`，不会当作书籍显示。
- **本机操作顺序**：“从云端删除”和书籍等内容同步在本机按先后依次执行，删除会等正在进行的同步写完清单；阅读时长同步和打开云端书籍时的下载不受影响。

## 多设备更新网络小说 EPUB

网络小说在阅读器“章节同步与更新”完成章节核对后，按书源/小说/章节 ID 和章内比例同步进度、书签，文件版本不同也能共用状态。文库与普通导入保持按文件哈希同步。旧书尚未核对时沿用原文件状态；仅把文件名或章节序号改成 ID 并不能建立对应。

1. 两台设备升级支持 ID 同步的版本，在各自书库书籍的“三个点 → 章节同步与更新”中“按目录核对章节”；只比较目录，不逐章请求正文。不能唯一匹配时手动确认，需要时单独预览正文。旧书不要求重新下载。
2. 手动同步后，另一台设备再同步，即可按章节 ID 恢复。旧版缺章/尚未核对会提示，不会仅因打开旧版就覆盖云端位置。进度按修改时间，书签包含删除记录。
3. 需要新增章节时，在一台设备“更新至最新章节”后同步；另一台可通过本机书的“从 WebDAV 获取新版 EPUB”直接取回同一文件。新版打开后复用该文件已保存的对应表，或继续核对。阅读器内更新只承接标题和正文均完全相同的唯一章节。

ID 进度、书签和与文件 SHA-256 绑定的章节对应表保存在独立的 `NoveliaSync/web-epub-v1/index.json`，沿用强 ETag/条件提交及冲突重读。旧客户端只操作原 `v1/`，不会过滤或覆盖独立目录；但108及以前不识别新状态，不能参与 ID 同步，所有参与设备应升级。原哈希记录保留作迁移与文库兼容，新目录保留已有小说状态和书签删除记录，不随旧清单文件版本筛掉。

取回云端文件会校验哈希并复核版本。相同文件不重复下载；不同文件仅接受下载时间更晚的云端版本，同时间不同内容提示冲突。本机较新、云端缺书/文件损坏、失败/取消或下载期间记录变化均不继续替换。普通同步仍不自动替换已有旧 EPUB。

## 服务器上的文件

服务器会生成 `NoveliaSync/v1/`，其中的下载文件与书目未做端到端加密。

| 路径 | 内容 |
| --- | --- |
| `index.json` | 书目（含文件大小）、阅读位置、书签、系列、标签、背景、字体记录与云端删除记录 |
| `blobs/` | 以内容哈希命名的书籍、背景图片与字体文件 |
| `statistics/<设备 ID>.json` | 各设备的阅读时长与设备名称；每台设备只写自己的文件，不要求服务器支持 ETag |
| `reading-statistics.json` | 旧格式的合并统计文件；只读取合并、不写入，见[与旧版本混用](#与旧版本混用) |

### 云端文件缺失时

- “立即同步”（手动同步）会先列出 `blobs/` 中已有的文件，清单引用却不在服务器上的文件（例如被手动删除）由本机补传，完成提示会说明补传了几个。
- 本机也没有的文件无法补传。这类云端书籍在书库中显示“云端文件缺失”（橙色图标），完成提示列出书名；打开时可选择“从云端删除”书目（阅读进度和统计保留），或在仍有这本书的设备上手动同步一次以补传。书目不会自动删除。
- 下载云端书籍时才发现文件缺失，同样会标记并给出这两个选择。缺失的封面只是不显示，不影响同步和下载。
- 自动同步为减少请求不做这项核对。服务器不支持列出目录时同步照常进行，但不会补传。

> [!NOTE]
> 不建议手动修改 `NoveliaSync/v1/` 中的文件；`index.json` 与 `blobs/` 由 App 维护。

## 与旧版本混用

多台设备的 App 版本不同时，较旧的版本不认识较新版本写入的部分记录。建议所有设备使用同一版本；无法全部升级时注意以下差异：

| 内容 | 不支持的版本 | 混用时的表现 |
| --- | --- | --- |
| 云端删除记录 | 0.20.0 之前 | 不识别删除记录，可能再次上传已从云端删除的书 |
| 书目中的文件大小 | 0.20.0 之前 | 写入的书目没有大小，其他设备下载确认显示“大小未知”，直到本机有相同版本的设备同步一次 |
| 书库系列 | 0.13.0 之前 | 同步时不识别系列，写回清单会丢弃云端系列；较新的设备本机仍保留，再次同步即可恢复 |
| 书签 | 0.22.0 之前 | 同步时不识别书签，写回清单会丢弃云端书签；较新的设备本机仍保留，再次同步即可恢复 |
| 编辑过的书库信息 | 0.22.0 之前 | 不识别修改时间，可能用旧书名覆盖云端记录，也不会套用其他设备的修改；修改过的设备本机仍保留，再次同步即可恢复云端记录 |
| 按设备的阅读时长文件 | 0.20.0 之前 | 0.18–0.19 测试版写入 `reading-statistics.json`；当前版本只读取合并该文件、不写入，所有设备升级后可删除 |

同一台设备在不同版本之间切换时：

- **EPUB 进度**：0.12.0 之前保存的进度只有整书比例，按比例恢复，位置可能略有偏差。
- **阅读统计**：从 0.21.2 起统计保存在 App 的文件中，升级时自动迁移原有记录。降级到更早的版本后，该版本看不到迁移前的统计；再次升级时，降级期间记录的时长会合并回来。
- **统计设备标识**：从 0.21.2 起保存在本机 Keychain。此前已经从备份恢复出的设备仍与原设备共用标识，无法自动区分。

## 已知限制

- 本机书库索引未成功读取时不会开始内容同步，以免将未加载的空列表当作真实书库；可先在书库重试读取。

- WebDAV 要求 HTTPS 与可写的 WebDAV 文件夹。自动同步只在 App 运行或刚进入背景时进行，不会在 App 关闭期间定时同步；自动同步尚未在真实服务器与多设备上验收。
- 只删除本机时，云端书目会保留，并在之后的同步中显示为云端书籍。
- 其他设备在删除之后才重新下载或导入的同一本书不会被删除。
- WebDAV 已由维护者用真实服务器实测，但不同服务端对条件写入与目录创建的支持可能有差异。

手动取回新版网络EPUB与网站更新共用本地旧/新文件比较钩子，继承唯一且正文未变的已确认章节，尊重新文件既有确认和墓碑，不请求网站正文。
