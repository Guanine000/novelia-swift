# WebDAV 同步

[← 返回 README](../README.md) · [功能说明](FEATURES.md) · [本机构建与分发](BUILD.md) · [许可与第三方软件](LICENSES.md)

Novelia iOS 通过手动 WebDAV 同步在多台设备间共享书籍、阅读进度和部分设置。

## 设置

1. 在“我的 → WebDAV 同步”打开同步开关。
2. 填入可写的 HTTPS WebDAV 文件夹地址、用户名和密码（或应用密码）。密码保存在 iOS 钥匙串。
3. 按需独立开启书籍同步（下载文件与阅读进度）、标签同步、阅读背景同步和导入字体同步。阅读时长统计另有默认关闭的统计同步开关和手动同步按钮，见[阅读时长统计](FEATURES.md#阅读时长统计)。

## 开始同步

- 在书库左上角点同步按钮开始。
- 同步过程中再次点按钮，可打开进度浮窗并取消任务。
- 另一台设备配置相同地址并同步后，会恢复云端较新的书籍记录。

## 合并规则

| 内容 | 规则 |
| --- | --- |
| 书籍 | 网络小说按下载时间、文库书按导入时间逐本比较，选择较新版本 |
| 阅读位置 | 按更新时间合并。网络小说记录章节序号；EPUB 记录整书与章内比例，便于在两种引擎间近似恢复；TXT 记录章节与分页单位 |
| 书库系列 | 每个系列和每本书的归属分别按修改时间合并 |
| 标签屏蔽 | 按每个标签最后修改时间合并，解除屏蔽也会同步 |

- **旧版兼容**：旧版应用同步时不识别系列信息，写回清单会丢弃云端系列；新版设备本机仍保留系列，再次同步即可恢复云端记录。
- **追加与恢复**：本地删除不会删除云端副本，后续同步可能再次恢复该书。
- **避免重复上传**：两端相同的书沿用清单中已上传的文件，不重复读取和上传；本机按文件路径、大小与修改时间缓存文件哈希。
- **取消**：取消不会回滚已经传输或恢复的文件，远端目录清单在同步最后阶段写入。

## 服务器上的文件

服务器会生成 `NoveliaSync/v1/`，其中的下载文件与书目未做端到端加密。

> [!WARNING]
> 清单已引用的文件不会重新上传，因此请勿手动删除 `NoveliaSync/v1/blobs/` 中的文件；若已误删，可在书籍齐全的设备上删除 `NoveliaSync/v1/index.json` 后重新同步，让该设备重新上传全部文件。

## 已知限制

- WebDAV 目前需在书库手动同步，要求 HTTPS 与可写的 WebDAV 文件夹。尚无后台自动同步。
- 删除不传播，云端书目会保留，并可能在之后的同步中恢复到本机。
- WebDAV 已由维护者用真实服务器实测，但不同服务端对条件写入与目录创建的支持可能有差异。
