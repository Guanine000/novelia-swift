# Novelia iOS 移植（基础版本）

这是一个独立的 SwiftUI iOS 项目，移植对照对象是第三方原生 Android 客户端 [nobYoQ/novelia](https://github.com/nobYoQ/novelia)。该 Android 客户端基于 [AutoNovel 网页版及服务端](https://github.com/auto-novel/auto-novel) 提供的服务开发。本 README 的功能差距清单以 Android 客户端为准，AutoNovel 是其上游网站/API 服务来源。**本 iOS 项目与这两个上游仓库分离，不会修改它们。**当前版本用于验证 iOS 上的基础发现、阅读和账号认证流程，尚未达到 Android 客户端的功能完整度。

## 当前已实现

- SwiftUI 三个主入口：书架、发现、我的。
- 发现页调用 Novelia 公开 API 搜索在线作品。
- 读取在线作品详情、章节目录和章节正文。
- 基础章节阅读，支持原文、译文、双语显示，以及上一章/下一章。
- 调整阅读字号；本地保存章节级阅读进度和章节书签。
- 在作品详情中选择网页端收藏夹收藏/取消收藏；书架登录后读取 Novelia 账号的云端收藏，并按账号缓存供离线查看。
- 小说账号统一认证流程：通过 WKWebView 登录，调用 refresh 接口获取应用令牌，并将令牌保存在 iOS Keychain。
- 最低部署版本为 iOS 17。

> 书架当前展示 Novelia 账号的网页收藏；本地收藏夹和云端书架的复杂管理尚未实现。

## 在 Xcode 中运行

1. 用 Xcode 打开 `NoveliaIOS.xcodeproj`。
2. 选择 `Novelia` scheme 和 iPhone 模拟器。
3. 点击 Run，或按 **⌘R**。

项目最低部署版本是 iOS 17。`Package.swift` 单独提供平台无关的 `NoveliaIOSCore` 模型和样例数据。当前工程已通过 arm64 iOS Simulator Debug 构建；最新认证改动仍需在模拟器或设备上完整验证。

## 项目结构

- `iOSApp/`：SwiftUI 页面、阅读器和账号认证。
- `Sources/NoveliaIOSCore/`：作品模型、样例数据、Novelia API 客户端和 Keychain 令牌存储。
- `NoveliaIOS.xcodeproj/`：Xcode 工程。
